# Preparación para Claude Certified Architect – Foundations (CCAR-F)

Los mejores recursos para preparar la **Claude Certified Architect – Foundations (CCAR-F)** están en la **Anthropic Partner Academy**: empieza por la guía oficial del examen, después haz los cursos gratuitos y practica con código real. La guía oficial es la fuente autoritativa del temario e incluye preguntas de ejemplo. [2]

## Recursos oficiales prioritarios

1. **Guía del examen (Exam Guide)** — en la página de la certificación dentro de [Anthropic Partner Academy](https://anthropic-partners.skilljar.com/page/faq-certifications). Define dominios, *task statements* y estilo de preguntas; léela antes que cualquier otro material. [2]
2. **Cursos de preparación gratuitos** — Anthropic Partner Academy ofrece formación a tu ritmo; para Foundations destacan:
   - *Claude Code in Action*
   - *Introduction to Model Context Protocol*
   - *Building with the Claude API*
   - *Introduction to Agent Skills* [5]
3. **Claude Cookbooks** — repositorio oficial de ejemplos ejecutables sobre tool use, RAG, agentes y MCP: [github.com/anthropics/claude-cookbooks](https://github.com/anthropics/claude-cookbooks). Úsalo para convertir conceptos en práctica real. [7]
4. **Documentación oficial** — consulta especialmente Agent SDK, MCP, tool use y Claude Code: [docs.anthropic.com](https://docs.anthropic.com/). El examen evalúa decisiones de arquitectura, no solo definiciones. [10]
5. **Programa oficial de certificación y registro** — [Pearson VUE – Anthropic](https://www.pearsonvue.com/us/en/anthropic.html). [1]

## Plan recomendado

1. Descarga y estudia la **guía oficial**; identifica los cinco dominios y sus pesos. [2]
2. Completa los cuatro cursos oficiales más alineados: API, Claude Code, MCP y Agent Skills. [5]
3. Construye un mini-proyecto con Claude API + MCP + Claude Code, usando los [Claude Cookbooks](https://github.com/anthropics/claude-cookbooks) como referencia. [7]
4. Haz un simulacro comunitario, revisa cada fallo y vuelve a la documentación oficial. [6]
5. Antes de reservar, usa el examen de práctica oficial como indicador: una referencia común es superar cómodamente 900/1000. [5]
